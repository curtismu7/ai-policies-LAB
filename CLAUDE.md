# ai-policies-LAB

Demo-tier standalone app: Ping "AI Policies: Scope and HITL" release claims (deck slide 52, release 2026-11-02): four layered scope checks (surface, application, action, end user), a third outcome that holds a call for a person, attended vs unattended evaluation, no held connection, single-use approvals bound to the exact call or to a period, where it can run (pre-call vs post-inspection) and fail closed. Simulated. **Every product claim is "Ping release claim, UNVERIFIED on our tenant"** (banner on every tab, presenter mode too).

- Run: `./scripts/run.sh` (http://localhost:7500). Test: `npm test` (server is `node --test test/*.test.js`, a glob; web is vitest against the real Express app; scripts). Preflight `npm run doctor`. Reset `npm run reset`. Docker: `HOST_PORT=7500 docker compose up --build -d`. Node 26 only.
- Modes: **Mock** (default) = tables (`server/src/mockTable.json`, generated by `npm run mock-table` from six scripted scenarios run through the engine; a doctor check and a test fail on drift; read-only, every write is 409). **Live** = the real local engine on the visitor's own actions, with REAL RS256 tokens minted here. Mock is loopback-only with zero outbound (netguard + a test); Real adds only the optional Privilege gateway check (below), to the one gateway origin.
- Core: `engine.js` (the pipeline: request, token, surface, application, action, end-user, attended/unattended, request inspection, call, reply inspection; approvals; lab clock; no I/O), `canon.js` (strict JSON parser and the canonical call hash), `token.js` (RS256 mint/verify, throwaway in-memory key), `policies.js` (six rule layers, validation on save), `catalog.js`, `inspect.js` (three finding kinds), `actions.js` (the one dispatch used by the API, scenarios and tests), `scenarios.js` (+ Mock table builder), `mask.js` (the shared masker 1.4.0 adapter; `server/src/shared/` is copied unchanged from shared-masker 9bc664a, never edited here) + `credentials.js` (cleanFree, cleanUnderKey, isCredentialKey, the inspector's normaliser), `service.js`, `app.js`. Web: `useLab` hook, seven tabs (Evaluate, Policies, Approvals, Where it runs, Fail closed, Diagram, Talk track).
- Rules that bite: scope is read from the VERIFIED token only (headers and arguments that claim a scope are ignored and listed); an error, a wrong-typed argument, a bad token, an unknown route all DENY; a rule naming a person, tool, scope, role or application that does not exist is refused when saved (a lab reading of a partly-cut-off deck line); inspection rules can only refuse or withhold, never hold; a grant is an input that can lift a hold and nothing above it; approvals freeze their requirements at creation and are re-checked when a retry would use them; the canonical form is lab-invented (`canon.js` header) and tested against key order, NFC, number formats, duplicate keys, `__proto__`; a credential the visitor types is masked on the way in and again on every response (values AND object keys) by ONE masker, the shared masker 1.4.0 (`mask.js`; `maskProse` only for the lab's own story, diagrams, info and Mock tables; `shown()` masks the canonical JSON as data; opaque values only in the exact shape the lab writes (including the hop's shortened `mcp-session-id` at `trace.listing|refusal.request|response.headers` only); `cleanFree` never deletes a character; `echo.test.js`, `masking-bypass.test.js`, `masker-corpus.test.js` and `typed-payloads.test.js` type every shape into every field, key, path segment, query and header; the limits are pinned in `masker-adoption.test.js`); the HTTP edge is 415 on a bad charset, 405 from the `API_ROUTES` table, 400 `bad_workspace` from `isCredentialId`, page shell only for `isPageAddress`, fixed JSON everywhere else (`http-edge.test.js`); at the workspace cap a new id is refused (503), never evicting, and the only token ever returned is the mint answer's `labToken`; honest HTTP codes (the browser logs 4xx as console messages); every user value used as an object key is type-checked; per-field source tags on every tab (`web/src/sources.js`, `FIELD_SOURCES`): the claim sources are tagged "deck claim", "console swagger name (schema only)", "lab reading", "lab-invented", "measured (our note)"; ports 7500-7549; UI: shared `web/src/styles/standalone-ui.css` vendored byte-for-byte, app CSS tokens only (`bash ~/Development/AI-DEMO-Standalone/scripts/check-css.sh .`).
- Settings: one shared file `~/Development/.env` (mode 600, `STANDALONE_ENV` overrides), parsed with `util.parseEnv` in `server/src/settings.js`; this lab takes only `AIP_LAB_MODE`, never a bare MODE.
- Run check-drift, check-css and conformance by hand. SE k8s build deferred (owner, 2026-10-31); no k8s manifests. Catalog id D109. Cross-references in text only: privilege-demo (Cedar enforcement) and agent-gateway-inspector (adding the same slide-52 ideas): neither is imported or touched.
- What Privilege did (rule 25): `web/src/gateway-trace/` (`GatewayTrace.jsx`, `gateway-trace.css`, `gateway-trace.test.jsx`, `gateway-trace.sha256`) and `server/src/gatewayTrace.js` are copied byte-for-byte from AI-DEMO-Standalone `shared/gateway-trace` and never edited (`scripts/gateway-trace.test.mjs` hashes them; re-vendor, then re-pin). `server/src/policyTrace.js` is this lab's builder: it turns one `engine.evaluate` decision into a `mockTrace` (source `mock`, every decision `checked`, a hold is `info`, host `gateway.<cast>.invalid`, token never shown, request passed through `scrub`). Live `/api/evaluate` returns it as `trace`; Mock builds it at read time in `mockState` from each evaluate step (the table is not regenerated). Only an evaluation is a gateway call: mint, approve, clock and policy saves carry none. Header Real here is the local engine, so the panel always says simulated (`basisNote`) and never uses source `real`. The name is `gatewayTrace.js`, never `trace.js` (the W3C traceparent helper).
- Real gateway hop (`APL_GW_URL`, `APL_GW_APPS`, `APL_GW_KEY_<NAME>`; settings file or environment): `server/src/gatewayReal.js` (vendored byte-for-byte from AI-DEMO-Standalone `shared/gateway-real/gatewayClient.js`, never edited, re-vendor by copy) and `web/src/privilege-check/` (`PrivilegeCheck.jsx`, `privilege-check.css`, from `shared/privilege-check`, byte-for-byte). `POST /api/gateway-check` is 409 in Mock (no call, `mock_mode`) and 409 `real_not_available` (with a `message` the card shows) without settings; in Real it calls `setAllowedOrigins([<gateway origin>])`, then one `tools/list` and one refusal probe with `capture: true`, and returns the answer plus `trace.listing` / `trace.refusal` built by `traceFromDoor` (source `real`, decisions only observed or inferred, never checked). The card (`web/src/components/GatewayHop.jsx`) renders only in Real and draws "Show what Privilege did" from the card's own `onResult` answer: no second gateway call. `server/src/policyTrace.js` and the Evaluate panel are unchanged (`mock`). Never put a gateway host, cluster or app name in this public repo (placeholders only).
