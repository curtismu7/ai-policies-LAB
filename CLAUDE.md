# ai-policies-LAB

Demo-tier standalone app: Ping "AI Policies: Scope and HITL" release claims (deck slide 52, release 2026-11-02): four layered scope checks (surface, application, action, end user), a third outcome that holds a call for a person, attended vs unattended evaluation, no held connection, single-use approvals bound to the exact call or to a period, where it can run (pre-call vs post-inspection) and fail closed. Simulated. **Every product claim is "Ping release claim, UNVERIFIED on our tenant"** (banner on every tab, presenter mode too).

- Run: `./scripts/run.sh` (http://localhost:7500). Test: `npm test` (server is `node --test test/*.test.js`, a glob; web is vitest against the real Express app; scripts). Preflight `npm run doctor`. Reset `npm run reset`. Docker: `HOST_PORT=7500 docker compose up --build -d`. Node 26 only.
- Modes: **Mock** (default) = tables (`server/src/mockTable.json`, generated by `npm run mock-table` from six scripted scenarios run through the engine; a doctor check and a test fail on drift; read-only, every write is 409). **Live** = the real local engine on the visitor's own actions, with REAL RS256 tokens minted here. Both loopback-only, zero outbound (netguard + a test).
- Core: `engine.js` (the pipeline: request, token, surface, application, action, end-user, attended/unattended, request inspection, call, reply inspection; approvals; lab clock; no I/O), `canon.js` (strict JSON parser and the canonical call hash), `token.js` (RS256 mint/verify, throwaway in-memory key), `policies.js` (six rule layers, validation on save), `catalog.js`, `inspect.js` (three finding kinds), `actions.js` (the one dispatch used by the API, scenarios and tests), `scenarios.js` (+ Mock table builder), `mask.js` (the shared masker 1.4.0 adapter; `server/src/shared/` is copied unchanged from shared-masker 9bc664a, never edited here) + `credentials.js` (cleanFree, cleanUnderKey, isCredentialKey, the inspector's normaliser), `service.js`, `app.js`. Web: `useLab` hook, seven tabs (Evaluate, Policies, Approvals, Where it runs, Fail closed, Diagram, Talk track).
- Rules that bite: scope is read from the VERIFIED token only (headers and arguments that claim a scope are ignored and listed); an error, a wrong-typed argument, a bad token, an unknown route all DENY; a rule naming a person, tool, scope, role or application that does not exist is refused when saved (a lab reading of a partly-cut-off deck line); inspection rules can only refuse or withhold, never hold; a grant is an input that can lift a hold and nothing above it; approvals freeze their requirements at creation and are re-checked when a retry would use them; the canonical form is lab-invented (`canon.js` header) and tested against key order, NFC, number formats, duplicate keys, `__proto__`; a credential the visitor types is masked on the way in and again on every response (values AND object keys) by ONE masker, the shared masker 1.4.0 (`mask.js`; `maskProse` only for the lab's own story, diagrams, info and Mock tables; `shown()` masks the canonical JSON as data; opaque values only in the exact shape the lab writes; `cleanFree` never deletes a character; `echo.test.js`, `masking-bypass.test.js`, `masker-corpus.test.js` and `typed-payloads.test.js` type every shape into every field, key, path segment, query and header; the limits are pinned in `masker-adoption.test.js`); the HTTP edge is 415 on a bad charset, 405 from the `API_ROUTES` table, 400 `bad_workspace` from `isCredentialId`, page shell only for `isPageAddress`, fixed JSON everywhere else (`http-edge.test.js`); at the workspace cap a new id is refused (503), never evicting, and the only token ever returned is the mint answer's `labToken`; honest HTTP codes (the browser logs 4xx as console messages); every user value used as an object key is type-checked; per-field source tags on every tab (`web/src/sources.js`, `FIELD_SOURCES`): the claim sources are tagged "deck claim", "console swagger name (schema only)", "lab reading", "lab-invented", "measured (our note)"; ports 7500-7549; UI: shared `web/src/styles/standalone-ui.css` vendored byte-for-byte, app CSS tokens only (`bash ~/Development/AI-DEMO-Standalone/scripts/check-css.sh .`).
- Settings: one shared file `~/Development/.env` (mode 600, `STANDALONE_ENV` overrides), parsed with `util.parseEnv` in `server/src/settings.js`; this lab takes only `AIP_LAB_MODE`, never a bare MODE.
- Run check-drift, check-css and conformance by hand. SE k8s build deferred (owner, 2026-10-31); no k8s manifests. Catalog id D109. Cross-references in text only: privilege-demo (Cedar enforcement) and agent-gateway-inspector (adding the same slide-52 ideas): neither is imported or touched.
